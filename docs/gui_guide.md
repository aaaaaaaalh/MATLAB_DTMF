# 第二阶段 GUI 操作与手动验收

启动：

```matlab
cd('E:\MATLAB_DTMF');
DTMF_App;
```

界面使用 uifigure、uigridlayout、uibutton、uiaxes 与 uitable；灰色面板、蓝色波形、中文标签。优先微软雅黑，候选字体包含黑体和 Noto CJK。小窗口启用滚动，不强行挤压控件。没有修改 MATLAB 全局字体设置。

## 基本操作

1. 点击 0～9 追加数字并试听当前键。取消“按键试听”可以静音录入；不影响完整号码播放。
2. `* 删除` 删除末位并重新合成剩余号码。`# 确认` 保留音频、显示确认标记、识别全部号码。二者都不作为普通音调追加。
3. 时间模式默认 300/100 ms。允许发声 40～3000 ms、间隔 0～2000 ms；零间隔无法保证分开连续按键，尤其重复数字。指导书模式锁定 1000/100 点，禁用毫秒输入框但保留原值以便切回。
4. “播放完整号码”实际播放当前音频，包括导入的 WAV。新播放先停止并释放旧播放器；“停止播放”、编辑号码、切换参数、导入和关闭窗口均停止原播放。
5. “识别当前音频”对当前波形分段识别；表格包含起止时间、频率、通过/不确定及原因。`?` 保留在完整号码中。
6. 下拉框或表格选择一个片段，时域红线标示区间，频谱使用核心 dtmfSpectrum 的 2048 点 FFT。红色三角为检测峰，虚线对应标称双频；下方显示数值和有效点数。无有效片段时显示中央帧频谱，不伪造按键频率。
7. WAV 导入自动平均声道、重采样、识别并更新两幅图。号码编辑框置空，与导入识别结果分开。导入后再按数字键会开始新拨号并替换当前显示音频，原磁盘文件不会修改；导入状态不支持按末位删除。
8. 导出保存完整当前音频，不只是选定频谱片段。取消文件对话框不改变会话。

## 自动检查

```matlab
addpath('tests');
results=run_phase2_checks;                 % 37 项，不播放声音
results=run_phase2_checks(RunAudio=true);  % 39 项，增加真实声卡测试
```

输出位于 outputs/results/phase2。声卡测试只是播放器 API 与资源释放检查，实际听感仍需人工确认。无声卡时硬件项标记未完成并使总检查非全通过，不隐藏跳过项。
