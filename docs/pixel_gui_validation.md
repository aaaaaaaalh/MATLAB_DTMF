## 用户手动验收

启动前关闭旧版 GUI；若当前 MATLAB 已加载旧类，请先关闭该应用窗口并执行 `clear classes`，或重启 MATLAB。

```matlab
cd('E:\MATLAB_DTMF');
DTMF_App;
```

1. 在实际显示缩放比例下查看中文标题、参数输入框、FFT 和底部表格；调整窗口大小，检查外层滚动和表格自身滚动。
2. 输入 8，检查 852/1336 Hz 峰值；输入连续号码，使用 * 删除和 # 确认；清空后重新输入。
3. 切换基准模式，检查参数禁用与恢复；在时间模式更改持续时间和间隔，再确认识别。
4. 实际听音：按键试听、播放完整号码、停止、快速重复播放、播放中关闭窗口。
5. 使用真实文件对话框导出 WAV，再导入并检查识别；取消对话框、选择坏文件时应保留原有行为与错误提示。
6. 切换按键下拉框和点击识别表格，检查选段边界和频谱同步；长号码滚动查看全部明细。
7. 后续改动继续在独立分支验收；既有稳定标签保持不变。

可自行重复原测试：

```matlab
addpath('tests');
run_tests;
run_phase2_checks;
% 可选：会播放声音，需要可用声卡
% run_phase2_checks(RunAudio=true);
```
