## 复现和指标

```matlab
cd('E:\MATLAB_DTMF');
results = run_phase3_experiments;
% 可调整实验规模，仍使用独立的确定性随机流：
% results = run_phase3_experiments(Seed=20261023, RandomCount=20, NoiseRepeats=10);
```

默认种子 20261023，随机数算法 twister。函数退出恢复调用者原 RNG 状态。配置含实际测试号码、逐次噪声种子公式、MATLAB/工具箱版本、Git 修订和源文件内容哈希。

字符级准确率使用 `max(0, 1 - 总编辑距离 / 总参考字符数)`，其中 Levenshtein 插入、删除、替换（含 ?）各计 1；完整号码必须逐字符完全相同。保留未截断的 CharacterErrorRate，因此大量额外片段可使该错误率大于 100%，准确率最低记为 0%。这不是仅比较相同位置或忽略多余字符的统计方法。

噪声 SNR 按**包含静音间隔的整段信号平均功率**定义；将每次高斯白噪声实测功率归一化到目标值，不削波、不写低 SNR 噪声到会削波的 PCM WAV。记录目标与实测 SNR。JSON 的 Inf 会编码为 null，config.json 另有 snrLabels；MAT 和 CSV 保留 Inf。无噪声仅每号码运行一次，不虚增重复样本。

当前算法和本批有限样本的统计不代表任意电话音频或任意噪声下的保证；不要与不同随机种子、样本集或 SNR 定义的早期实验直接合并。

## A～F 实际结果

| 实验 | 样本/条件 | 结果 |
| --- | --- | --- |
| A 频率 | 全部 12 键，默认 300 ms 单音 | 12/12 正确，最大频率绝对误差约 0.0621 Hz |
| B 连续号码 | 指定 3 组 + 固定种子随机 20 组，234 字符 | 字符与完整号码准确率均 100%，23/23 |
| C 时间参数 | 7 种持续时间 × 4 种间隔 + 1000/100 点基准，每组 5 号码 | 145 次，92 次完全正确，53 次失败；详细条件见下文 |
| D 抗噪 | 两模式；无噪声及 30/20/15/10/5/0 dB；共 366 次 | 61 条实际失败，详细见下表 |
| E 采样率 | 8000/16000/44100/48000 Hz × 单/双声道 × 3 号码 | 24/24 完全正确；全部读取为 8192 Hz 单声道 |
| F 异常 | 8 个正常拒绝/错误提示场景 | 8/8 符合预期 |

C 的持续时间为 20、30、40、60、120、200、300 ms，间隔为 0、10、30、100 ms，CSV 同时保存实际取整后的采样点数。20/30 ms 用于底层压力实验，不改变 GUI 原有最小 40 ms 限制。

- 持续时间 ≥40 ms 且间隔 10/30/100 ms：本批每个条件 5/5 正确。
- 1000/100 点基准：5/5 正确。
- 20 ms：所有间隔均 0/5，单音有效长度不足为主要限制。
- 30 ms、非零间隔：每组完整号码 4/5，字符准确率 97.8723%。单音原长度为 246 点，分段边缘可带入静音，因此不可把 256 点判决门槛直接等同于固定持续时间门槛。
- 零间隔：所有持续时间完整号码均 0/5。算法无法保证在没有静音边界时正确分开连续音调，尤其重复数字。

| SNR | 默认字符 / 完整号码 | 基准字符 / 完整号码 |
| --- | --- | --- |
| 无噪声 | 100% / 100%（3/3） | 100% / 100%（3/3） |
| 30、20、15、10 dB | 均 100% / 100%（各30/30） | 均 100% / 100%（各30/30） |
| 5 dB | 100% / 100%（30/30） | 99.3103% / 96.6667%（29/30） |
| 0 dB | 0% / 0%（0/30） | 0% / 0%（0/30） |

具体错误示例：基准模式 5 dB、第 3 次噪声试验，`0123456789` 识别成 `0123?6789`，编辑距离 2，含“组内峰值显著性不足”拒绝原因。0 dB 默认模式产生大量多余片段，总编辑距离 504 / 290 参考字符，原始错误率 173.7931%，未隐去插入错误。全部 114 条失败（C 53、D 61）保存在 recognition_errors.csv。

F 包含：静音与空序列返回空结果；128 点单音返回 ? / rejected；无效字符、不可读文本格式、空 WAV 导出、空会话识别、NaN 音频返回相应异常。文件格式试验是实际不支持的文本内容，不宣称底层 audioread 会拒绝所有非 WAV 编码。
