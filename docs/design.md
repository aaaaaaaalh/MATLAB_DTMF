# 第一阶段算法设计

## 调用关系

`dtmfConfig → dtmfSequence → dtmfTone → dtmfFrequencies` 提供两种独立参数模式和标准音调生成。单正弦默认幅度 0.45，上限 0.5，因此两路叠加不超过满量程。显式 Samples 优先于 Duration；空号码返回空波形。

`dtmfReadWav → audioread → 通道平均 → resample` 统一到 8192 Hz。立体声采用算术平均，完全反相的两通道可能抵消，这是此策略的已知限制。`dtmfWriteWav → audiowrite` 使用 24 bit PCM，超范围输入统一缩放到峰值 0.999，保持双频相对幅度。

`dtmfRecognizeSequence → dtmfRecognizeTone → dtmfSpectrum` 完成自动分段与 FFT 判决。演示脚本连接合成、导出、导入、识别和绘图。

## FFT 判决

有效帧少于 256 点返回不确定。先检查去直流均方能量不低于 1e-10。长音调取中央最多 2048 个有效样点，短音调按实际有效长度加 Hann 窗，再零填充到 2048 点。FFT 栅格为 8192/2048=4 Hz；零填充不会提高由有效数据时长决定的真实频率分辨率。

在七个标准候选频率的 ±16 Hz 内寻峰，对数幅度三点插值得到频率估计。低高两组各取最大候选；估计频率需在标称 ±12 Hz 内。两组的最强候选均需为组内其他候选的至少 3 倍，低高幅度比不低于 0.25，两峰各 ±24 Hz 区域总功率占比至少 60%。任何条件失败均返回 `?` 和原因。这是教学用判决器，不宣称满足通信设备标准。

单边幅度谱按窗系数和归一化，内部正频率倍增；功率按 `NFFT*sum(w.^2)` 归一化并倍增内部正频率。返回 FFT 点数、有效样点数与栅格间隔，避免混淆。

## 连续分段

使用 4 ms 滑动均方能量，基于第 10/95 百分位构造自适应门限。能量门限下限为 1e-10，主体取 `min(0.25*P95,max(4*P10,0.10*P95))`。无静音的单键不会因为噪声底估计偏高而整体漏检。

只填补最长 2 ms 的内部能量缺口，以合并同一音调中的短片段。不会因为相邻字符相同就合并，所以 100 点（约 12.2 ms）真实静音隔开的重复数字可以保留。长度不足 12 ms 的能量活动视作脉冲干扰；其余有效区间逐个 FFT 判决，过短或频谱不合格返回 `?`。边界会受到滑窗影响，测试容许 6 ms 偏差。

已知边界：零间隔的同频重复键不可辨识；无静音的不同键切换没有专用变化点检测。极短间隔、强噪声、较大音量跳变及片段内频率变化可能导致漏分或拒判。当前门限基于整段统计，并非逐音节局部门限。未进行标准 DTMF 接收器合规认证。

## 测试与噪声记录

`testDtmf.m` 提供 21 个测试函数，参数循环覆盖 12 个键、两种模式、持续时间/间隔组合、四种输入采样率、低音量、噪声、拒判和音频往返。噪声固定种子 20261022，六个 SNR（30、20、10、5、0、-5 dB），每模式每 SNR 10 次，共 120 个完整序列实验。SNR 以有效发声功率计算，噪声加入含头尾静音的完整波形。

噪声 CSV 汇总记录模式、SNR、测试数、正确数、准确率和失败号码；另存全部逐次结果。正确标准是完整号码精确匹配。SNR≥10 dB 作为待实际验证的回归要求；更低 SNR 如实记录能力边界。测试失败仍保存结果并使 batch 非零退出。
